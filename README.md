# Web Development Workshop: My Identity Dashboard

17週間で、自分専用の高度なダッシュボードを構築するワークショップのカリキュラムリポジトリです。

## 🚀 ディアゴスティーニ方式
本ワークショップは、毎週一つの「パーツ」を作り上げ、最終的に巨大なプロジェクトを完成させるスタイルを採用しています。

### Phase 1: HTML & CSS (Weeks 1-4)
- セマンティックHTML、CSSデザイン、Flexbox/Gridレイアウト、レスポンシブ。

### Phase 2: JavaScript & Git (Weeks 5-9)
- DOM操作、イベント、非同期通信（Fetch API）、Gitによるバージョン管理。

### Phase 3: React & Next.js (Weeks 10-13)
- モダンフロントエンドへの移行、TypeScript、コンポーネント設計。

### Phase 4: Specialization (Weeks 14-17)
- カスタマイズとデプロイ。

---

## 📂 リポジトリ構成
- `/lessons`: 講義用スライド構成（Marp形式）
- `/project-core`: **あなたの作業用メインフォルダ**。毎週ここを育てていきます。
- `/milestones`: 各週の完成見本（チェックポイント）。コードが動かなくなった時に参照してください。

## 🛠 開発ルール
1. **一歩ずつ進む:** 前週のコードをベースに新しい機能を「組み付け」ます。
2. **Gitを活用する:** 毎週の区切りで `commit` し、自分の成長を記録しましょう。
3. **「なぜ」を大切に:** セマンティックなタグ選びや、効率的なCSS設計を意識します。
